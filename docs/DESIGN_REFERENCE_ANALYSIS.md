# Design reference analysis

The assignment calls for the Movexa references as the primary direction and Shakuro’s [Healthcare Dashboard](https://dribbble.com/shots/25554152-Healthcare-Dashboard-for-Clinic-Management-Patient-Management) as a secondary reference for patient-management information architecture.

The supplied written direction informed the application’s horizontal workspace navigation, warm neutral canvas, restrained coral accents, patient initials, compact rows, floating notifications and slide-over admission form. AdmitFlow uses an original wordmark treatment and does not ship the referenced media. At narrow widths, the desktop directory becomes a card list and the main navigation moves to the bottom with a central admission action.
